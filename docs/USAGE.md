# 使用录映

## 选择录制来源

1. 选择「显示器」「窗口」或「区域」。
2. 点击对应的选择按钮。窗口模式会打开窗口选择，显示器与区域模式会打开显示器选择。
3. 在 macOS 系统选择器选择内容，确认共享。应用会显示所选名称。
4. 区域模式使用显示器内左上角起算的逻辑像素：`x,y,宽,高`，例如 `0,0,1280,720`。
5. 按「开始录制」，结束后按「停止录制」。未选择来源时，开始按钮会自动打开选择器。

切换录制类型会清除旧选择，避免误录其他内容。应用前台快捷键为 **⌘⇧R**。录制存到 `~/Movies/OpenScreenStudio/`。

## 声音与摄像头

- 系统声音和麦克风独立控制。麦克风捕获需要 macOS 15+。
- 开启摄像头会保存独立 MOV，导出时合成到画面右下角。
- 摄像头、屏幕和音频支持同步暂停／继续，暂停时间不会计入成片。
- 第一次启用各设备可能出现系统授权。拒绝后请在对应隐私设置中修改。

## 编辑与导出

默认播放器展示原素材。设置起止秒数、速度、画幅、输出宽度、边距和背景后，按「效果预览」会生成最多 8 秒的本地效果片段。正式导出使用完整选定区间。

自动缩放与点击提示需要同名 JSON 鼠标轨迹。录制时关闭「显示原始鼠标」可使用合成圆点；已经录进画面的原鼠标无法后期无损移除。

导入 SRT 字幕按原视频时间处理，裁剪和变速时自动调整字幕时间。生成本地字幕需要 Apple 本机识别支持所选语言；不支持或资源未安装时会报错，不会上传音频。

可导入背景音乐与图片，并使用普通音频降噪。音频降噪效果依素材而异。MP4 支持音频，GIF 不支持。

导出显示百分比与预计剩余时间（实际时间会受效果复杂度影响）。可随时取消，失败后按「重试上次导出」。新成片通过验证后才替换目标文件；取消或失败不会覆盖原成片。

## 项目

编辑参数也会自动保存到 `~/Library/Application Support/LuYing/Recovery.ossproject`，重启会恢复上次编辑。录制、保存和导出期间退出会被阻止，请先停止或取消任务。录制启动前需要至少 512 MB 空间，录制期间不足 128 MB 会停止并尝试保存；这不能保证覆盖所有崩溃或断电情况。

保存 `.ossproject` 可恢复路径与编辑参数。它不打包素材；请保持原视频、摄像头文件、背景音乐、图片和字幕的路径。

## 常见问题

**启动被阻止**：安装包没有 Apple Developer ID 公证，使用系统「隐私与安全性 → 仍要打开」流程。不要关闭系统安全保护。

**录屏授权反复弹出／列表为空**：使用最新版的「选择显示器…／选择窗口…」。它通过系统内容选择器授权，应用启动时不自动请求录屏。

**导出报找不到程序**：v0.2.0 完整版已自带导出组件，无需安装开发工具。如果组件缺失，请重新下载并解压完整安装包，勿只复制应用内部的单个可执行文件。

**字幕识别失败**：检查语音识别授权及系统语言资源。也可导入已有 SRT。

**搜索出现两份应用**：只保留「应用程序」里的安装版，删除下载目录里的解压副本；ZIP 本身不会产生第二个应用入口。
